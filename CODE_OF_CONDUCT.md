# Código de conduta para colaboradores
## Objetivo
Este repositório hoje é mantido por apenas 1 colaborador. Espera-se que todas as contribuições priorizem qualidade, segurança, respeito e colaboração.

<p align="right">(<a href="#topo">voltar ao topo</a>)</p>

## Princípios
- Buscar compartilhamento de conhecimento e colaboração.

<p align="right">(<a href="#topo">voltar ao topo</a>)</p>

## Desenvolvimento
Ao contribuir para este projeto:
- Siga os padrões de codificação predefinidos.
- Mantenha código simples, legível e testável.
- Evite duplicação desnecessária.
- Documente alterações relevantes.

<p align="right">(<a href="#topo">voltar ao topo</a>)</p>

## Pull Requests
- Todo código passará por revisão antes do merge.

<p align="right">(<a href="#topo">voltar ao topo</a>)</p>

## Segurança e Dados
- Não expor credenciais, senhas, tokens, chave ou qualquer tipo de informação sensível.
- Nunca utilizar dados reais em testes ou exemplos.
- Reporte imediatamente exposições identificadas!
